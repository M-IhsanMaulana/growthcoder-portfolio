Cara Mengoptimalkan Kinerja Query Eloquent pada Laravel 13

Laravel Eloquent ORM adalah fitur yang sangat powerful dan memudahkan kita dalam melakukan manipulasi database. Namun, di balik kemudahannya, Eloquent sering kali menyembunyikan query yang tidak perlu jika tidak digunakan dengan hati-hati.

Masalah performa yang paling sering dijumpai adalah problem N+1 Query. Artikel ini akan membahas taktik mengatasinya secara efektif pada Laravel 13.

1. Memahami Masalah N+1 Query

N+1 Query terjadi ketika Anda mengambil daftar data utama (misalnya 50 user), lalu memanggil data relasinya (misalnya profile) secara individual di dalam perulangan loop. Ini menyebabkan Laravel melakukan 1 query untuk mengambil user, dan 50 query tambahan untuk mengambil masing-masing profile. Total 51 query database dijalankan!

"N+1 query adalah silent killer pada performa aplikasi backend Anda. Selalu periksa log database saat memuat relasi data."

2. Menggunakan Eager Loading dengan with()

Solusinya adalah memberi tahu Eloquent untuk mengambil data relasi secara sekaligus (bulk) menggunakan metode with(). Laravel hanya akan menjalankan 2 query saja.

Contoh Buruk (Menimbulkan N+1 Query):

// Mengambil data user
$users = User::all();

// Di dalam view / loop:
foreach ($users as $user) {
    echo $user->profile->bio; // Query tambahan dipicu disini
}

Contoh Baik (Menggunakan Eager Loading):

// Mengambil data user beserta profilnya sekaligus
$users = User::with('profile')->get();

foreach ($users as $user) {
    echo $user->profile->bio; // Mengambil dari memori cache Eloquent
}

3. Menerapkan Strict Mode pada Model

Pada Laravel 13, Anda dapat mengaktifkan Strict Mode untuk mencegah terjadinya lazy loading di lingkungan lokal development. Tambahkan kode berikut pada AppServiceProvider Anda: 

use Illuminate\Database\Eloquent\Model;

public function boot(): void
{
    // Memicu Exception jika terjadi Lazy Loading di local env
    Model::preventLazyLoading(! $this->app->isProduction());
}

Dengan begini, jika Anda tidak sengaja menulis query lazy loading, aplikasi akan memunculkan error crash saat penulisan kode, memaksa Anda memperbaikinya sebelum dideploy ke produksi.
